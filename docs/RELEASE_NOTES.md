First public release.

Create, load and delete snapshots of a Mortal Shell save slot. Loading backs up the slot it overwrites, and the program warns you when the game is running.

Put `MortalShellSaveManager.exe` in its own folder and run it. The source code is in the repository for anyone who wants to check it first.

The SHA-256 checksum of the `.exe` is attached as `MortalShellSaveManager.exe.sha256`.
